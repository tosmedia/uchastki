# Участки под Москвой — выборка с ЦИАН

Сайт: **https://tosmedia.github.io/uchastki/**

Подбор земельных участков по данным [cian.ru](https://www.cian.ru), собранный 3 сентября 2026 года.

## Критерии отбора

| Параметр | Значение |
|---|---|
| Цена | до 15 000 000 ₽ |
| Расстояние от МКАД | до 10 км |
| Площадь | 6–10 соток |
| Статус земли | ИЖС или садоводство |
| Коммуникации | электричество + газ + водоснабжение |
| Регион | Москва и Московская область |

**Найдено: 89 участков** — 62 ИЖС и 27 садоводство. Цены от 2,09 до 15 млн ₽, медиана 9,5 млн ₽.

## Возможности

- Карточки с фотографией, ценой, площадью, ценой за сотку, расстоянием от МКАД, шоссе, адресом и продавцом. Клик по карточке открывает объявление на ЦИАН.
- **Карта Яндекса** под списком: метки по координатам объявлений, синие — ИЖС, зелёные — садоводство, близкие собраны в кластеры. Карта подчиняется фильтру над списком. В баллоне метки — фото, цена, ссылка на ЦИАН и кнопка «Показать в списке».
- **Галочка** «Выбрано», **оценка от 1 до 3 звёзд** и **текстовая заметка** на каждой карточке. Повторный клик по той же звезде снимает оценку.
- **Фильтры**: все / с галочкой / со звёздами / только 3★ / с заметкой.
- **Сортировка**: по близости к МКАД, по цене, по оценке. Активные фильтр и сортировка подсвечены и продублированы строкой состояния.
- Отметки и заметки сохраняются в `localStorage` браузера. Они локальные: другие посетители сайта их не видят и на сервер ничего не уходит. Кнопки «Сохранить отметки» / «Загрузить отметки» переносят их между браузерами и устройствами через JSON-файл.

## Что в репозитории

`index.html` — всё целиком в одном файле. Единственная внешняя зависимость — JS API Яндекс.Карт для карты; если он недоступен, список и отметки работают как обычно, а на месте карты появляется сообщение. Файл можно скачать и открыть локально — работает так же.

## Формат данных

Исходный набор лежит внутри `index.html` в блоке `<script type="text/plain" id="dataset">` — обычный текст с разделителем `|`:

```
id|price|area|status|dist|hw|addr|seller|photo|host|lat|lng
```

- `status` — `i` (ИЖС) или `g` (садоводство)
- `dist` — расчётное расстояние от МКАД в километрах
- `photo` — имя файла на `images.cdn-cian.ru/images/`
- `host` — поддомен ЦИАН для ссылки на объявление
- `lat` / `lng` — координаты для метки на карте

Чтобы обновить выборку, достаточно заменить строки в этом блоке — вёрстку трогать не нужно.

## Оговорки

- **Расстояние от МКАД** посчитано по координатам объявления: расстояние до центра Москвы минус 17,5 км (средний радиус кольца). Погрешность ±2 км. Собственное поле ЦИАН «км по шоссе» показывает путь по трассе до населённого пункта и для ближнего пояса часто завышено вдвое-втрое, поэтому не используется.
- **Метки на карте** стоят по координатам из объявления — это точка населённого пункта, СНТ или улицы, а не границы конкретного участка. У двух объявлений одного СНТ координаты могут совпадать.
- **Коммуникации** заявлены продавцом в объявлении и ЦИАН их не проверяет. Канализация в фильтр не входила. Наличие сетей и статус земли обязательно проверять по документам.
- Из выдачи ЦИАН (95 объявлений) исключены 2 объекта, которые по координатам дальше 15 км от МКАД (Подольск, Домодедово) — фильтр ЦИАН выдал их ошибочно, — и 4 участка площадью 10,2–10,6 сотки.
- У 8 из 89 объявлений ЦИАН не отдаёт фотографию — в каталоге у них серая плашка.
- Фотографии подгружаются напрямую с сервера ЦИАН. Объявления со временем снимаются с публикации, тогда картинка исчезнет, а ссылка приведёт на 404.
